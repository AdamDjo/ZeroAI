# Skills et outils

- `hatch-pet` : génération, assemblage, QA et packaging des mascottes.
- `skill-creator` : création du workflow spécialisé de Zéro.

## Skill spécialisé créé

`hatch-zero-evolution` orchestre les trois stades, préserve l’identité adulte, produit les packages de croissance, prépare les traits de breeding et refuse les combinaisons non validées. Il se trouve dans `~/.codex/skills/hatch-zero-evolution/`.

Scripts fournis :

- `normalize_extra_row.py` ;
- `assemble_stage_app_atlas.py` ;
- `validate_genome.py` ;
- `breed_genome.py`.

Voir [[HATCH-ZERO-EVOLUTION]].
