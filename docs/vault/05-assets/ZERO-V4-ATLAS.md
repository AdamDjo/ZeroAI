# Atlas actif

## Source de vérité

`assets/v4/final/ZERO_MASTER_V1.png` et `assets/v4/final/ZERO_CANONICAL_BASE.png` définissent l’identité adulte.

Signatures obligatoires :

- corps crème chaud ;
- grand visor noir ;
- yeux pixel lime ;
- cœur IA lime au collier ;
- queue noire avec orbe lime ;
- silhouette de chat compacte et lisible.

## Contrat runtime

- 8 colonnes ;
- 15 rangées ;
- cellules de 192 × 208 ;
- 13 animations aux rangées 0 à 12 ;
- 16 regards aux rangées 13 et 14 ;
- 97 poses utilisées.

Le mapping exact se trouve dans `assets/v4/final/pet.json`. Les contrôles se trouvent dans `assets/v4/final/qa/`.

## Règle

Les futurs stades et variations génétiques ne remplacent pas l’adulte. Chaque morphologie validée possède son propre master et son propre atlas, avec le même contrat logique.
