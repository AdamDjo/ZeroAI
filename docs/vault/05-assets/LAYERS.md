# Layers

## Ordre de composition prévu

1. ombre optionnelle ;
2. corps du stade ;
3. palette ou marques de pelage ;
4. visor et expression ;
5. cœur IA et orbe ;
6. cosmétique derrière le corps ;
7. cosmétique principal ;
8. effets de données et feedback.

Chaque calque partage la même grille, la même cellule et la même origine que l’atlas du stade. Un trait qui modifie la silhouette utilise un atlas validé par stade ; une couleur ou une petite marque peut utiliser un masque/palette.

Les signatures de Zéro restent visibles, sauf animation temporaire explicitement conçue pour les révéler à nouveau.
