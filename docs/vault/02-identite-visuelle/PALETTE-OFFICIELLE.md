# Palette officielle

## Rôles

| Rôle | Couleur attendue |
|---|---|
| Pelage | crème chaud / blanc cassé |
| Visor, oreilles, collier, queue | charbon / presque noir |
| Yeux, cœur IA, orbe, données | lime lumineux |
| Ombres | gris chaud discret |
| Blush optionnel | corail très léger |

Les valeurs exactes sont échantillonnées depuis `assets/v4/final/ZERO_MASTER_V1.png` lors de la construction du catalogue de palettes. Elles seront stockées dans un fichier machine lisible avant la première recoloration runtime.

## Interdits par défaut

Pas de violet dominant, bleu néon, arc-en-ciel, métal chromé ou multiplication de verts. Une variation génétique de palette doit rester une palette approuvée, contrastée et testée avec le visor.
