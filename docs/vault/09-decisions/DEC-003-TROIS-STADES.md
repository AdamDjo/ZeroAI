# Décision

Le modèle Zéro V4 actuel représente l’**adulte**. Le produit doit aussi disposer d’un **bébé** et d’un **adolescent**.

## Conséquences

- trois masters canoniques ;
- trois packages d’animation compatibles ;
- aucune réduction automatique de l’adulte pour simuler la jeunesse ;
- identité visuelle commune aux trois stades ;
- breeding appliqué à un génome indépendant du stade ;
- rendu des traits adapté à chaque morphologie.

## Motivation

Trois stades suffisent à rendre la croissance visible et émotionnelle sans multiplier prématurément les atlas.
