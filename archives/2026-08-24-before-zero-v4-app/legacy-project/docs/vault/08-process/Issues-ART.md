# Backlog visuel adaptable

Les anciennes issues ART à treize étapes décrivaient le pipeline V1. Elles ne
constituent plus une séquence obligatoire.

## Unité de travail actuelle

Un run `hatch-pet` produit un candidat complet :

```text
concept ou références
→ base canonique
→ lignes d'animation
→ atlas
→ contact sheet et GIFs
→ QA
```

## Types d'issues utiles

| Type | Quand l'utiliser |
|---|---|
| candidat | explorer une nouvelle créature ou direction |
| réparation | corriger une ligne précise |
| rythme | ajuster vitesse, boucle ou transition |
| packaging | mettre à jour sheet et manifest |
| intégration | vérifier le rendu dans l'application |

Le nombre d'animations et de frames vient du candidat et du scénario testé.
Il peut évoluer sans recréer tout le backlog.

Voir [[Animations-MVP]], [[Retry-Et-Escalade]] et [[Human-Gates]].
