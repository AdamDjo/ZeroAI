# MOC — Assets

## Production actuelle

- [[Production-Master]] — base canonique par candidat ;
- [[Animations-MVP]] — états disponibles et évolutifs ;
- [[Sprite-Sheets]] — assemblage pour l'application ;

- [[Retry-Et-Escalade]] — réparation ou nouvelle direction.

## Principe

Le catalogue n'est pas fixé à un nombre d'expressions, d'animations ou de
frames. `hatch-pet` produit un pack cohérent ; l'intégration révèle ensuite ce
qui mérite d'être ajouté, remplacé ou supprimé.

## Au-delà du personnage

[[Anchors]], [[Layers]], [[Cosmetiques]], [[Evolution-Stages]] et [[Breeding]]
restent optionnels jusqu'à ce que le personnage principal fonctionne dans le
produit.

La V1 est un historique. Le candidat V2 est disponible mais sa créature reste à
revoir.
