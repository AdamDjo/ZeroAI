# Base canonique d'un candidat

Chaque run `hatch-pet` possède une image de base qui sert de référence à ses
animations. Cette base verrouille uniquement la cohérence du run en cours.

## Création

La base peut provenir d'une image, de plusieurs références, d'une retouche ou
d'une nouvelle description. Un turnaround complet est optionnel.

```text
idée ou références
→ base hatch-pet
→ animations du candidat
→ contact sheet et GIFs
→ garder, réparer ou remplacer
```

## Versionnement

Une direction différente crée un nouveau candidat. Les anciennes bases restent
inchangées pour permettre la comparaison et le retour arrière.

Le checksum sert à identifier une version, pas à interdire un redesign.
