# Périmètre MVP adaptable

## Objectif

Le MVP doit prouver qu'une mascotte animée paraît vivante et utile dans
l'application. Il n'impose pas un nombre universel de frames, d'émotions,
d'accessoires ou de stades d'évolution.

## Minimum utile

```text
1 candidat animé cohérent
1 état neutre convaincant
les états nécessaires au scénario testé
1 manifest
1 lecteur dans l'application
1 QA technique et visuelle
```

Le candidat V2 fournit déjà neuf états et peut servir de test. Une nouvelle
créature peut utiliser plus ou moins d'états si son rendu est meilleur.

## Hors priorité immédiate

- catalogue massif de vêtements ;
- tous les âges ou évolutions ;
- toutes les émotions imaginables ;
- combinaisons d'accessoires pré-rendues ;
- architecture complexe avant le premier rendu dans l'application.

## Critère de décision

Ajouter un asset lorsqu'il améliore une scène réelle. Le supprimer ou le
reporter lorsqu'il existe seulement pour remplir un tableau.
