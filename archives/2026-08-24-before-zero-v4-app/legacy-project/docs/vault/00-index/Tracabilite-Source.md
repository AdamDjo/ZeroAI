# Traçabilité Source

Chaque nœud de ce vault indique en pied de page les sections du master plan
dont il dérive, sous la forme `§N`.

## Fichier source

```text
ZERO_AI_ASSET_FACTORY_MASTER_PLAN.md   (v2.0, 4089 lignes, 210 sections)
```

## Statut du fichier source

Le master plan reste dans le repo comme **archive de référence**, mais il
n'est plus le document de travail. Les agents lisent le vault.

Si le master plan et le vault divergent : **le vault fait foi** (il est
maintenu, le master plan est figé). Toute correction du vault doit être
reportée dans le master plan uniquement lors d'une révision explicite.
