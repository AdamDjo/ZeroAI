# Identité du personnage

## Ce qui est décidé

Le projet cherche une mascotte numérique expressive, attachante et vivante.
Le workflow de production retenu est `hatch-pet` et son nom de travail reste
**Chimi**.

## Ce qui reste ouvert

La créature actuelle ressemble à un chat. Son apparence peut évoluer si un
autre candidat produit un meilleur rendu.

Sont encore révisables :

- espèce ou forme de la créature ;
- silhouette et proportions ;
- palette ;
- orbe, collier et accessoires ;
- style graphique ;
- personnalité visuelle et expressions.

## Candidat chat actuel

Le chat crème, les oreilles et la queue noires, l'orbe vert, le collier et le
blush décrivent le candidat actuel. Ils servent à contrôler sa cohérence, mais
ne sont pas des contraintes imposées à tous les futurs candidats.

## Critères de sélection

Le candidat retenu doit :

- être reconnaissable immédiatement ;
- rester lisible à petite taille ;
- donner envie de le regarder souvent ;
- supporter plusieurs émotions et mouvements ;
- rester cohérent dans une animation complète ;
- produire un rendu propre avec le pipeline `hatch-pet`.
