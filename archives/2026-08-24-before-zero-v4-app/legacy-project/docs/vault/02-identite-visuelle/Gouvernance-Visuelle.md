# Gouvernance visuelle évolutive

## Objectif

La gouvernance sert à comparer les candidats et à éviter les erreurs
accidentelles. Elle ne sert pas à figer la créature trop tôt.

## Liberté créative

Entre deux candidats, on peut changer :

- créature ou espèce ;
- silhouette et proportions ;
- palette et matière ;
- style pixel, illustré, sticker, 3D ou autre style compatible `hatch-pet` ;
- accessoires et marqueurs visuels ;
- liste et mise en scène des animations.

## Cohérence d'un candidat

À l'intérieur d'un même candidat, la référence canonique du run prévaut afin
que ses frames restent cohérentes. Une dérive accidentelle est un défaut ; une
nouvelle direction volontaire est un nouveau candidat.

## Sources utiles

```text
1. demande créative actuelle
2. références fournies pour le run
3. base canonique générée par hatch-pet
4. manifest et QA du candidat
5. anciens candidats comme comparaison seulement
```

Les prompts, références, candidats retenus, manifests et rapports sont
conservés pour rendre les choix réversibles.
