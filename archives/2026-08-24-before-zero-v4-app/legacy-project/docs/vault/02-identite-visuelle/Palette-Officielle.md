# Palettes par candidat

Il n'existe pas encore de palette finale obligatoire. Chaque candidat peut
explorer une palette différente si elle améliore son identité et sa lisibilité.

## Palette du candidat chat historique

```json
{
  "cream": "#FFF7EA",
  "ink":   "#1A1A1A",
  "lime":  "#A6E22E",
  "coral": "#FFBC7A",
  "mist":  "#EAF3E1"
}
```

Cette palette reste utile pour reproduire ce candidat. Elle ne s'applique pas
automatiquement à une nouvelle créature.

## Validation

La palette doit être cohérente entre les frames d'un même candidat, lisible à
petite taille et compatible avec la transparence. Le nombre exact de couleurs,
les gradients et le niveau d'anti-aliasing dépendent du style choisi.

Voir [[Style-Bible]], [[Validation-Palette]] et [[Gouvernance-Visuelle]].
