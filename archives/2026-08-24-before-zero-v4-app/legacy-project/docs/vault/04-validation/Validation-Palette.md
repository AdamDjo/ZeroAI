# Validation de palette

La palette est comparée à la base canonique du candidat en cours.

## Vérifier

- couleurs dominantes cohérentes entre les frames ;
- contrastes suffisants à petite taille ;
- absence de chroma key ou de halo sur les contours ;
- variations compatibles avec le style choisi.

Une nouvelle palette est autorisée pour un nouveau candidat. Pixel-art,
illustration lissée, sticker ou rendu 3D n'utilisent pas les mêmes seuils de
variation.

Voir [[Palette-Officielle]], [[Style-Bible]] et [[Validation-Identite]].
