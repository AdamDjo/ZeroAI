# Validation de cohérence visuelle

La validation compare les animations à la base canonique du candidat en cours,
pas à une créature historique obligatoire.

## Vérifications

- même créature au sein du run ;
- visage, silhouette, palette et accessoires cohérents ;
- proportions stables sauf déformation volontaire de l'action ;
- aucun membre coupé ou élément parasite ;
- état et mouvement lisibles.

## Changement volontaire

Changer l'espèce, la palette ou les marqueurs visuels n'est pas une dérive si
cela fait partie d'un nouveau candidat. Dans ce cas, sa nouvelle base devient
la référence de comparaison.

Les scores automatiques aident au tri. La contact sheet et les GIFs restent
nécessaires pour juger le mouvement réel.
